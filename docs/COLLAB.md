## A Strong First Message

Short and specific works best:

```text
Subject: Collaboration idea: <short project name>

What I'm building:
<one or two sentences>

The technical problem:
<what is hard or worth solving>

What exists now:
<repo, demo, notes or current status>

Where you might fit:
<backend, API design, system design, DevOps, DSA, etc.>

A first small milestone:
<something we can actually start with>
```

## Good Fit / Not a Fit

| Good fit | Probably not a fit |
|:--|:--|
| A concrete problem with a visible technical path | A vague idea with no next step |
| Open-source or learning-focused projects | Unpaid, open-ended commercial work |
| Respectful, steady communication | Last-minute, unplanned deadlines |
