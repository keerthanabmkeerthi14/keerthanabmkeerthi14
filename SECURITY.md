# Security Policy

This repository mostly contains Markdown, SVG images and links, but security reports are still welcome.

## What to Report

- Exposed secrets, tokens or private information.
- Suspicious or malicious links in the README or docs.
- Unsafe third-party images, badges or widgets that this repository references.

## How to Report

Please **don't open a public issue**. Contact me privately through the channels listed in the README and include:

- A short summary of the problem.
- The affected file, link or asset.
- Steps to reproduce or check it.
- The possible impact, and a suggested fix if you have one.

## What to Expect

This is a personal profile, not a production package, but I aim to review genuine reports promptly. Confirmed issues will be fixed by removing exposed data, replacing unsafe links or assets, and crediting the reporter if they wish.

## Disclosure

Please give me reasonable time to fix a problem before sharing it publicly.
