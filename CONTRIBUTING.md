# Contributing

Thanks for your interest. This repository is my profile, so contributions are mainly about keeping it accurate, clear and accessible.

## Helpful Contributions

- Fixing typos, broken links or layout problems.
- Reporting images, badges or widgets that no longer load.
- Suggesting clearer wording or better accessibility (alt text, contrast).

For collaboration on projects, see [docs/COLLAB.md](docs/COLLAB.md) or contact me through the README.

## Before You Open a Pull Request

- Keep changes small and focused.
- Please open an issue before large changes to the layout or style.
- Don't add heavy external dependencies or new third-party services without a clear reason.
- Never include secrets or private information.

## A Good Pull Request

- Explains what changed and why.
- Includes a screenshot for visual changes.
- Mentions any new external image, badge or service.

## Security

Please don't report security problems publicly. Follow [SECURITY.md](SECURITY.md).
